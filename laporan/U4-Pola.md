# 1. Pastikan Anda berada di root folder repository proyek Anda
# 2. Buat atau update file di dalam folder laporan/
# (Setelah menyimpan file laporan/U4-Pola.md dari draft di atas)

# 3. Tambahkan perubahan file ke dalam git staging
git add laporan/U4-Pola.md

# 4. Lakukan commit dengan pesan yang jelas
git commit -m "feat: menambahkan dokumen U4 Pola Arsitektur untuk BAB III"

# 5. Push commit ke repository GitHub/GitLab kelompok Anda
# (ganti 'main' dengan nama branch Anda jika berbeda)
git push origin main
